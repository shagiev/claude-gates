# Актуальная модель Cursor reviewer — дизайн

Дата: 2026-11-03. Tier: 2 — выбор ревьюера влияет на независимость deploy-гейта.

## Задача

Убрать устаревание захардкоженной `cursor-grok-4.5-high`, не включая `auto` и не ослабляя
независимость ревьюера. По умолчанию выбирать самую новую доступную Grok-модель по фактическому
`cursor-agent models`; `auto` и скрытая маршрутизация запрещены.

## Решения и альтернативы

- **Просто обновить константу до 4.7.** Отвергнуто: повторится та же проблема при следующем
  релизе модели.
- **Включить `auto`.** Отвергнуто: скрытая маршрутизация, нет аттестации фактической модели.
- **Динамический выбор по `cursor-agent models`. Выбрано.** Команда с коротким таймаутом возвращает
  фактические доступные ID. Из них выбирается Grok с максимальной числовой версией (`major.minor`),
  с сохранением семейного разнообразия. `CURSOR_REVIEW_MODEL` остаётся явным override, но тоже
  обязан присутствовать в этом списке и быть не-Anthropic.
- **При недоступном списке использовать старую константу.** Отвергнуто: это возврат к устаревшей
  модели молча. Отсутствие списка/подходящих моделей — fail-closed.

## Сценарии и приёмочные критерии (BSAC)

- **S1. Новая версия доступна.** Список содержит 4.5, 4.6, 4.7 → выбирается 4.7, независимо от
  порядка строк. Проверка: `resolve_cursor_model`.
- **S2. `cursor-` префикс необязателен.** `grok-4.7-high` и `cursor-grok-4.6-high` оба распознаются;
  4.7 выигрывает. Проверка: parser + resolver.
- **S3. Версии не сравниваются лексикографически.** 4.10 старше 4.9, 4.7 новее 4.6. Проверка:
  числовой tuple.
- **S4. Override.** `CURSOR_REVIEW_MODEL=<доступная модель>` используется даже если есть более новая;
  `auto`, Claude, неизвестный ID и ID вне списка — ошибка.
- **S5. Ошибка списка.** CLI не найден, rc != 0, timeout, пустой список, нет Grok, нет валидных
  кандидатов → `(None, причина)`, ревью не запускается. Нет fallback на устаревшую модель.
- **S6. Семейства.** Anthropic и `auto` отклоняются даже при наличии в списке. Не-Anthropic модель
  из списка допускается как fallback, если Grok нет, но `auto` не используется.
- **S7. Вызов ревью.** Адаптер использует выбранную модель в `--model` и пишет её в audit;
  список запрашивается с ограниченным таймаутом, без реальных сетевых вызовов из тестов.

## EARS

- **EARS-1.** WHEN список содержит несколько Grok-версий, THE resolver SHALL выбрать максимальную
  числовую версию независимо от порядка строк и префикса `cursor-`.
- **EARS-2.** IF модель не является Grok, is `auto`, Anthropic или отсутствует в фактическом списке,
  THEN resolver SHALL отклонить её.
- **EARS-3.** IF список нельзя получить или в нём нет подходящей модели, THEN resolver SHALL вернуть
  ошибку и не запускать ревью.

## Намеренно вне охвата

- Рейтинг качества моделей кроме версии: не придумываем метрику, используем только доступность и
  числовую версию.
- Кэширование списка между процессами: оно увеличивает окно устаревания; запрос идёт при каждом
  резолве.
