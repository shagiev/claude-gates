# Changelog

## 0.6.0 — 2026-07-26

- **Pre-push интеграционный гейт** (`prepush_gate.py` + шим `.githooks/pre-push`). Обещание
  ровно одно: **слияние с базой не конфликтует**. Конфликты предсказываются `merge-tree` без
  касания рабочего дерева; тесты на смерженной пробе (отдельный worktree, git-хуки отключены)
  запускаются, красные блокируют, а **зелёные не доказывают ничего** — при editable install
  импорт разрешается в настоящее дерево, и пометка об этом печатается ВСЕГДА. Спека:
  `docs/2026-07-26-prepush-integration-gate-design.md` (5 редакций, цикл закрыт на хард-капе).
- **Анти-самоослабление** секции `integration`: референс — предыдущий принятый tip ПУШИМОГО
  ref'а (`<remote sha>`), а не база (она не двигается до мержа). Нечитаемый предыдущий tip,
  пересоздание ветки и пуш по неразрешимому URL блокируются, а не читаются как «новая ветка».
- **Обходы раздельные и аудируемые**: `INTEGRATION_SKIP` (весь гейт), `INTEGRATION_TESTS_SKIP`
  (только тесты — конфликты всё равно проверяются), `INTEGRATION_CONFIG_CHANGE` (смена секции),
  `on_fetch_failure: skip-audited`. Запись в аудит делает сам `_ack`, поэтому будущий вызывающий
  не может её забыть.
- **Security-проход нашёл и закрыл два RCE-класса** (эксплойты воспроизведены): `base_ref` из
  пушимого коммита уходил позиционным argv в `git fetch`, и значение `--upload-pack=<cmd>`
  исполнялось; `merge_test_command` бралась из пушимого коммита, то есть чужая ветка исполняла
  свою команду на машине пушащего при рядовом `git push`. Теперь ref-компоненты валидируются
  (без ведущего дефиса), везде `--end-of-options`, а исполняемая команда читается ТОЛЬКО из
  конфига оператора; политика по-прежнему из коммита (анти-лаундеринг).
- `gates-run` различает «плагин не установлен» и «версия старше шима»: рассинхрон версий
  заблокировал все пуши в репо-носителе, а сообщение диагностировало не ту причину.
- Прочее из ревью: полный путь ветки вместо последнего сегмента (`release/main` считался базой
  и пропускал проверку), `HEAD:refs/heads/x` больше не даёт вечный ложный блок, база по
  умолчанию берётся из `origin/HEAD`, сбой `rev-list` — «неизвестно» → блок.
- Тесты: 384 → 449 (65 по этому гейту), мутационные проверки на каждом круге.

## 0.5.0 — 2026-07-26

- **Роли в лесенке разведены** (`_PASS_RUNNER`): текст гейта больше не утверждает ничего о
  конкретной машине — доступность команды и `disable-model-invocation` зависят от окружения,
  а плагин едет в произвольные репо. Правило одно: запускай проход сам, если платформа даёт
  команду; если отвечает `disable-model-invocation` — проси оператора и жди, но **не подменяй
  проход собственным вычитыванием**. `begin` печатает, чем выполняется проход. Замер 26.07:
  `/security-review` и `/simplify` вызываются моделью, `/code-review` и
  `/codex:adversarial-review` — нет.
- **Новая подкоманда `companion-review`**: единственный внешний вход к движку ревью — она
  ВЫПОЛНЯЕТ ревью, а не печатает argv. Скилл `design-review` больше не собирает вызов сам
  (самосборка теряла `CODEX_COMPANION_CMD`, а при непопадании глоба давала `node ""` с кодом 0,
  чей пустой вывод читался как «замечаний нет»). Fail-closed во всех ветках: нет движка,
  пустой вывод при коде 0, деградировавший конверт (исчерпанная квота) → код 2 с причиной.
- **Общий `_exec_companion`** — единственное место запуска движка: резолв, таймаут, редакция
  argv в диагностике. При ненулевом коде причина берётся из stdout (там её рендерит companion),
  а не только из stderr.
- **Корень репозитория вместо cwd** (`_repo_root`): `begin`/`mark` из подкаталога писали
  бухгалтерию в `<subdir>/.claude/`, pre-commit её не находил, и коммит блокировался при
  выполненных проходах. Pre-existing баг, найден ревью 26.07.
- **Сообщение блокировки и баннер `begin` не выдумывают путь шима**: если `.githooks/gates-run`
  нет (проект с чужим `core.hooksPath`), печатается плейсхолдер, а не строка, дающая
  `command not found`.
- **Реестр недоверенного текста** дополнен источником #10 (тело дизайн-ревью) с обоснованием
  осознанного исключения из редакции.
- **Исправлены два ложных покрытия**, найденные мутациями: регресс R5-F2 проходил впустую
  (`sleep 5 --api-key=…` не спит, ветка таймаута не выполнялась), тест дословности вывода
  использовал пейлоад, на котором редакция ненаблюдаема. Изоляция companion-окружения
  перенесена в общий conftest и ВЫСТАВЛЯЕТ инертную команду вместо удаления переменной —
  удаление снимало последний барьер перед живым Codex.
- Методология: `docs/2026-07-26-instruction-text-as-gate-surface.md`. Спеки следующих тикетов:
  `docs/2026-07-26-pass-evidence-design.md` (ревью не пройдено, см. раздел ниже),
  `docs/2026-07-26-prepush-integration-gate-design.md`. Тесты: 367 → 384.

## 0.4.0 — 2026-07-25

- **Переключение ревьюера** `REVIEW_PROVIDER=codex|cursor|both`: неизвестное значение блокирует
  (без тихого фолбэка); адаптер cursor в коде с пиньованной моделью `cursor-grok-4.5-high`
  (другое семейство, чем codex/gpt-5.6-sol); оверрайд только из не-Anthropic allow-list —
  `claude-*` и `auto` запрещены навсегда. Расход (in/out токены) и фактический бинарь пишутся
  в аудит. Спека: `docs/2026-07-25-reviewer-provider-switch-design.md` (approved, 5 раундов),
  эмпирика выбора модели: `docs/2026-07-25-cursor-fallback-reviewer-research.md`.
- **Режим `both`**: union находок с пометкой провайдера, блок при blocking у любого, ОДИН раунд
  сходимости, второй проход даже при blocking первого; отказ любого → блок без деградации, но
  находки успевшего сохраняются как частичный раунд (счётчик раундов не жжётся).
- **Сессионное выключение ревьюера** `review-disable/enable/status`: громкий баннер, обязательная
  причина, авто-истечение со сменой сессии; G1 пропускает (fail-open by design), деплой и
  check-decision блокируют — проверка ДО кэш-ветки.
- **Кэш чистого ревью привязан к идентичностям** `{провайдер, модель}` и переоценивается по
  текущему allow-list; вердикт для inframon — схема 2 с полем `providers`.
- **Строгий контракт ответа ревьюера**: ровно одна строка `Verdict:`, весь остаток обязан
  соответствовать грамматике, детектор явного отказа в narration — отказ ревьюера больше не
  засчитывается одобрением (5 раундов ревью кода закрыли этот класс).
- **Редакция секретов** в operator-facing выводе у 9 источников недоверенного текста (7 раундов
  ревью): помеченные пары, схемы аутентификации, префиксы провайдеров, JWT, подписи в URL, DSN,
  длинные токены; диагностика при этом сохраняется дословно. Тесты: 322 → 367.

## 0.3.0 — 2026-07-25

- **Третий обязательный проход лесенки `security`** (`DEPLOY_REQUIRED_PASSES = simplify,
  code-review, security`). Мотив: плагин `security-guidance` сообщает находки ПОСТ-фактум,
  не блокирует и не оставляет следа для деплой-гейта, а его LLM-слой идёт на Claude-модели —
  линза, но не независимость. Цепочка проверяется по КАЖДОМУ звену; `begin security`
  валидируется против `code-review.tree_after`.
  **Обратная совместимость:** grandfathering по происхождению записи — post-commit нового кода
  штампует `ladder_schema: 2`; записи без поля (писал старый код) валидируются легаси-набором
  из двух проходов, поэтому обновление НЕ блокирует деплой существующих проектов.
  Спека: `docs/2026-07-25-security-ladder-pass-design.md` (Codex-approved, 2 раунда).
- **Security-класс в конституции ревьюера** (`AGENTS.skeleton.md` + своя `AGENTS.md`): внешний
  ввод в опасный сток (shell/SQL/path traversal/десериализация/SSRF/eval), секреты (хардкод и
  утечка в логи/аудит), авторизация (IDOR/обход), слабая криптография — теперь их судит
  независимое ревью диффа.
- Эмпирика резервного ревьюера: `docs/2026-07-25-cursor-fallback-reviewer-research.md`
  (выбор модели по качеству и затратам); спека переключения провайдеров/`both`/сессионного
  выключения — `docs/2026-07-25-reviewer-provider-switch-design.md` (approved, реализация
  предстоит).
- Диагностика quota-отказов Codex: причина (`usage limit`) видна оператору вместо «дрейфа
  схемы»; регрессы всех форм отказа + живая фикстура. Тесты: 278 → 299.

**Обновление:** `/plugin uninstall gates@lenar-gates` + `/plugin install gates@lenar-gates`
(`/plugin update` молча не работает; клон маркетплейса подтягивается сам при add/install).

## 0.2.0 — 2026-07-24

Все фичи прошли цикл: спека → Codex adversarial-review до approve → TDD → лесенка →
Codex-ревью кода до approve.

- **Эмпирический гейт** (#1): `empirical.test_command` как условие деплоя, порядок
  ladder → empirical → Codex; трёхстатусная модель конфига (absent доказывается `git
  ls-tree`, git/parse-сбой = unreadable = блок); снятие/подмена команды после включения —
  блок без аудируемого `EMPIRICAL_SKIP`; биндинг всего прогона к `head_before`; argv без
  shell.
- **Дрейф-детектор design-маркера** (#3): маркер биндится к дизайн-файлу (reviewed-hash из
  результата ревью, set-модель для нескольких дизайнов, per-session lock); правка дизайна
  после пометки → G1 блокирует правки кода до ре-ревью. Методология: пост-ревью правки =
  ре-ревью; destructive-операции — blocking-категория конституции.
- **Структурная валидация BSAC** (#2): file-маркер требует секцию сценариев/BSAC/EARS
  (пере-выводится из hash-валидированного контента — анти-разъезд версий; EARS — токен,
  YEARS/APPEARS не ловятся); стаб рушит coarse-маркер.
- **Интерфейс к внешнему guard'у (inframon)**: `deploy.baseline_command` — authoritative
  deployed-SHA (no-fallback при отказе, pin секции против самоскрывающихся изменений,
  аудируемые env-переходы); машиночитаемый вердикт `logs/review_verdicts/<sha>.json`
  (schema 1, run_id, скипы видимы включая исторические `covered-with-skips`,
  delete-then-write под локом).
- Рефакторы: generic SHA-bound читатель секций конфига, общий `_atomic_write_json`,
  `_design_gate`. Тесты: 192 → 278.

## 0.1.0 — 2026-07-22

Порт боевой системы гейтов в плагин: G1 дизайн-гейт (PreToolUse-хуки, opt-in по
`.codex-gate.yaml` worktree-OR-HEAD), enforced-лесенка `/simplify`→`/code-review`
(begin/mark, tree-chain, git-хуки-шимы с авторитетным резолвом версии), commit-bound
деплой-гейт `check-reviewed` с протоколом сходимости (finding-ledger, адъюдикации,
carry-over, эскалация). Конфиг `.codex-gate.yaml` со строгими дефолтами и жёсткими
код-путями; анти-лаундеринг незастейдженного конфига; скиллы `design-review`/`gates-init`;
шаблоны (AGENTS-скелет, Makefile-snippet, githooks). 192 теста.
